# 统一服务(Unified Service) API接口文档（前端版）

## 概述

统一服务是一个集成了认证服务、智能体服务和知识库服务的综合服务平台，提供统一的API接口。

## 基础信息

- **基础URL**: `http://localhost:5002` (开发环境)
- **响应格式**: JSON
- **字符编码**: UTF-8

## 通用响应格式

所有API响应均采用以下格式：

typescript

```
interface BaseResponse {
  success: boolean;
  message?: string;
  error?: string;
  data?: any; // 具体接口数据
}
```



## 接口列表

### 2. 智能体服务 (Agent Service)

#### 2.1 创建任务

- **URL**: `/agent/tasks`
- **方法**: `POST`
- **请求参数**:

typescript

```
{
  workflow_type?: string; // 工作流类型，默认'default_workflow'
  task_data: {
    query: string;        // 查询内容
  };
}
```



- **响应**:

typescript

```
{
  success: boolean;
  task_id: string;
  message: string;
}
```



#### 2.2 获取任务列表

- **URL**: `/agent/tasks`
- **方法**: `GET`
- **响应**:

typescript

```
{
  success: boolean;
  tasks: any[]; // 任务列表
}
```



#### 2.3 获取任务详情

- **URL**: `/agent/tasks/<task_id>`
- **方法**: `GET`
- **路径参数**: `task_id` - 任务ID
- **响应**:

typescript

```
{
  success: boolean;
  task: {
    task_id: string;
    status: string; // pending, running, completed, failed
    created_at: string;
    current_step: number;
    total_steps: number;
    results: any;
  };
}
```



#### 2.4 更新任务

- **URL**: `/agent/tasks/<task_id>`
- **方法**: `PUT`
- **路径参数**: `task_id` - 任务ID
- **请求参数**:

typescript

```
{
  action: string;     // 操作类型，如'resume'
  resume_data?: any;  // 恢复数据
}
```



- **响应**:

typescript

```
{
  success: boolean;
  message: string;
  result: any;
}
```



#### 2.5 删除任务

- **URL**: `/agent/tasks/<task_id>`
- **方法**: `DELETE`
- **路径参数**: `task_id` - 任务ID
- **响应**:

typescript

```
{

  message: string;
}
```



#### 2.6 启动任务

- **URL**: `/agent/tasks/<task_id>/start`
- **方法**: `POST`
- **路径参数**: `task_id` - 任务ID
- **响应**:

typescript

#### 2.7 停止任务

typescript

### 3. 知识库服务 (Knowledge Service)

#### 3.1 上传文件

- **URL**: `/knowledge/upload`
- **方法**: `POST`
- **请求格式**: `multipart/form-data`
- **请求参数**:
  - `file`: File - 文件对象
- **响应**:

typescript

```
{
  success: boolean;
  message: string;
  filename: string;         // 原始文件名
  stored_filename: string;  // 存储文件名
  file_size: string;        // 文件大小
  upload_time: string;      // 上传时间
}
```



#### 3.2 获取文件列表

- **URL**: `/knowledge/files`
- **方法**: `GET`
- **响应**:

typescript

```
{
  success: boolean;
  files: Array<{
    filename: string;
    stored_filename: string;
    file_size: string;
    modified_time: string;
  }>;
}
```



#### 3.3 智能问答

- **URL**: `/knowledge/ask`
- **方法**: `POST`
- **请求参数**:

typescript

```
{
  question: string; // 问题内容
  history?: any[];  // 历史对话记录，可选
}
```



- **响应**:

typescript

```
{
  success: boolean;
  answer: string;    // 回答内容
  sources: any[];    // 来源信息
  timestamp: string; // 时间戳
}
```



#### 3.4 删除文件

- **URL**: `/knowledge/delete/<filename>`
- **方法**: `DELETE`
- **路径参数**: `filename` - 存储的文件名
- **响应**:

typescript

```
{
  success: boolean;
  message: string;
}
```

## 错误处理

### HTTP状态码

- `200`: 请求成功
- `400`: 请求参数错误
- `401`: 未授权，需要登录
- `403`: 禁止访问
- `404`: 请求的资源不存在
- `500`: 服务器内部错误

### 错误响应格式

typescript

```
{
  status: "error";
  message: string;    // 错误描述
  error_code?: number; // 错误代码
}
```



## 使用说明

1. **认证流程**:
   - 先调用登录接口获取session_id
   - 后续需要认证的接口会自动使用cookie中的session信息
   - 登出后清除session
2. **文件上传**:
   - 使用FormData格式上传
   - 支持常见文档格式
3. **任务管理**:
   - 创建任务后返回task_id
   - 可通过task_id查询任务状态和结果

## 注意事项

1. 开发环境基础URL为 `http://localhost:5002`
2. 生产环境请替换为实际部署地址
3. 所有接口支持CORS跨域访问
4. 需要登录的接口会返回401状态码，请引导用户登录
